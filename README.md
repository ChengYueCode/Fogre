# forge · 锻造

**先自己想，再看答案。**

读过资料，却说不清、用不上？Forge 让 AI 陪你把一个主题学明白：用例子讲解，通过提问和练习找出卡住的地方，再留下记录，方便以后继续。

你提供想学的主题或已有材料，就可以开始。

## 能帮你做什么

- **学新知识**：围绕你的目标讲解、提问，让你自己尝试。
- **整理资料**：把笔记整理成可交互的学习页和可编辑的思维导图。
- **继续学习**：根据保存的作答与反馈，接着上次的进度学习或复习。

## 开始使用

Forge 是安装在 AI 助手里的学习技能。需要助手支持技能加载、文件读写和命令执行；生成学习页和保存档案还需要 Node.js 20 及以上。环境问题见[安装指南](docs/installation.md)。

**第一步：请你的 AI 助手帮你安装。** 把这句话发给它：

```text
请从 https://github.com/ChengYueCode/Fogre 安装 forge 主技能，检查运行环境，并告诉我如何加载使用。已有同名技能时，请先核对现有安装。
```

**第二步：确认安装并加载后，告诉它你想学什么。** 例如：

```text
$forge 我想学概率，请用生活中的例子带我入门。
```

后续像平常聊天一样交流：不懂时让它换个例子，想整理资料时把材料交给它，结束前请它保存进度。下次在原工作区请它查找已有记录，再继续学习。

## 学习记录怎么保存

学习记录保存在你选择的本地目录中。请让 AI 告诉你保存在哪里；换电脑或工作区时，需要带上这些文件。

如果直接打开 HTML 学习页做题，新增答案先留在浏览器里，需要从页面导出后交给 AI，才能接着复核。通过本地服务打开的页面可以直接存档。具体操作见[保存与续学](docs/installation.md#保存与反馈交接)。

AI 的讲解和反馈可能出错；生成学习页或做完练习，也不代表已经掌握。
