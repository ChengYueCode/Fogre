# forge · 锻造

**先自己想，再看答案。**

读过资料，却说不清、用不上？Forge 让 AI 陪你把一个主题学明白：用例子讲解，通过提问和练习找出卡住的地方，再留下记录，方便以后继续。

你提供想学的主题或已有材料，就可以开始。

## 能帮你做什么

- **学新知识**：围绕你的目标讲解、提问，让你自己尝试。
- **整理资料**：把笔记整理成可交互的学习页和可编辑的思维导图。
- **继续学习**：根据保存的作答与反馈，接着上次的进度学习或复习。

## 开始使用

Forge 是安装在 AI 助手里的学习技能。需要助手支持技能加载、文件读写和命令执行；生成学习页和保存档案还需要 Node.js 20 及以上。环境问题见[安装指南](docs/installation.md)。

**第一步：请你的 AI 助手帮你安装。** 把这句话发给它：

```text
请从 https://github.com/ChengYueCode/Fogre 安装 forge 主技能，检查运行环境，并告诉我如何加载使用。已有同名技能时，请先核对现有安装。
```

**第二步：确认安装并加载后，在你使用的工具里选择 `forge` 技能，再告诉它你想学什么。**

调用方式由工具决定：[Claude Code](https://code.claude.com/docs/en/skills) 使用 `/forge`；[Codex CLI / IDE](https://learn.chatgpt.com/docs/build-skills#how-chatgpt-and-codex-use-skills) 可用 `/skills` 选择，或输入 `$` 选择 `forge`。其他工具按其技能菜单或调用提示操作。

选择技能后，输入你的学习目标。例如：

```text
我想学概率，请用生活中的例子带我入门。
需要时帮我整理学习页和思维导图，保存进度，并告诉我下次怎样继续。
```

后续像平常聊天一样交流：不懂时让它换个例子，想整理资料时把材料交给它，结束前请它保存进度。下次在原工作区请它查找已有记录，再继续学习。

## 主技能怎么用

`forge` 适合从开始到续学的完整过程。你提供主题、材料和已有基础，它先了解你的目标、提出问题并等你回答，再根据卡住的地方讲解、安排练习和反馈；需要时生成学习产物，保存本次记录。

如果已经有资料，选择 `forge` 后也可以直接说：“把我提供的笔记整理成学习页和思维导图，保留疑问，今天先不提问。”如果已有学习记录，把目录或档案交给它，请它读回进度后继续。

**只安装主技能就能使用下面的全部能力。** 想集中完成某一件事时，才需要考虑独立技能。

## 独立技能怎么用

五个独立技能都可以单独安装和使用。把第一步安装请求中的 `forge` 换成表中的技能名；安装并加载后，选择那个技能，再提供材料或已有档案，并发送相应请求。

| 独立技能 | 你需要提供什么、可以怎样说 | 你会得到什么 |
| --- | --- | --- |
| `forge-organize` 整理资料 | 提供笔记或文章：“整理成学习页和可编辑导图，保留我的疑问和来源。” | 学习页、导图、练习与来源说明；不进行现场问答 |
| `forge-question` 提问检查 | 提供自己的解释：“请通过提问检查我的理解，每次问一个问题。” | 一次一个追问，等待你回答；纯会话交流，不生成学习文件 |
| `forge-review` 复核作答 | 提供已有学习档案：“检查我已提交的答案，说明哪里正确、哪里有问题。” | 逐项反馈、核对依据与修补建议，写回学习档案 |
| `forge-review-plan` 安排复习 | 提供已有学习档案：“根据记录安排 15 分钟复习，优先补我反复出错的地方。” | 本轮复习内容、选择理由，以及暂缓的项目 |
| `forge-insights` 汇总理解变化 | 提供已有学习档案：“汇总我的原答、修正和反复出现的误区。” | 按概念汇总已有记录的“洞见与速查” |

例如，安装 `forge-organize` 后，Claude Code 可用 `/forge-organize` 调用；Codex CLI / IDE 可在技能列表中选择 `forge-organize`，再发送整理请求。其他独立技能使用同样的方法。

复核、复习安排和洞见汇总需要可读取的学习档案，只有旧聊天记录时，应先让 AI 确认是否具备所需记录。更多例子见[使用场景](skill/forge/references/usage-examples.md)。

## 会有什么产出

产出取决于你的请求：提问检查可以只在会话里进行；要求整理材料或需要学习产物时，AI 才生成相应文件。

| 产出 | 你可以怎样使用 |
| --- | --- |
| **交互学习页**（HTML） | 在浏览器中查看知识关系、阅读概念、作答、记笔记和查看已有反馈 |
| **可编辑思维导图**（`.excalidraw`） | 用 Excalidraw 打开，调整节点、文字和布局；需要时还可生成 SVG 预览 |
| **本地学习档案** | 保留目标、真实作答、修正、反馈和暂停位置，供下次继续学习或安排复习 |
| **会话中的问题、反馈或复习安排** | 直接在 AI 会话中交流；是否另存档案取决于本次任务和实际保存情况 |

例如，你请它整理概率笔记，可以得到一份可打开的学习页、一份可编辑导图，以及同一主题的学习目录。做过题并保存后，下次可根据原答和反馈继续。[查看概率示例的文件与使用说明](examples/probability/README.md)。

## 学习记录怎么保存

学习记录保存在你选择的本地目录中。请让 AI 告诉你保存在哪里；换电脑或工作区时，需要带上这些文件。

如果直接打开 HTML 学习页做题，新增答案先留在浏览器里，需要从页面导出后交给 AI，才能接着复核。通过本地服务打开的页面可以直接存档。具体操作见[保存与续学](docs/installation.md#保存与反馈交接)。

AI 的讲解和反馈可能出错；生成学习页或做完练习，也不代表已经掌握。
