# 三种学习法在 forge 中的落点

forge 把三种方法蒸馏为一条学习循环：确定要会什么 → 看清知识关系 → 自己解释或应用 → 根据缺口修正 → 把问题留到下次检索。学习笔记记录理解与修正，学习记录保存实际作答依据。

| 方法与机制 | forge 中的学习动作 | 可核对的产物与证据 |
|---|---|---|
| 费曼：用自己的话检验理解 | 学习者先解释；导师追问条件、反例或迁移；针对缺口修补后再解释 | 自己的解释、原始作答、后续修正分别保留；已解释/已应用需引用实际独立作答 |
| 西蒙相关抽象：目标聚焦与组块 | 收敛可观察目标；组织相关概念和前置；根据表现选择下一步 | 主题目标、父子层级与前置/因果/对比/应用关系；恢复学习先处理到期题与前置缺口 |
| 康奈尔：笔记转为可检索线索 | 学习者生成自己的问题；隐藏参考作答；反思并复用 | 自创问题进入练习和复习，原答案与反馈分开显示；解释与总结绑定到同一概念 |
| 后续保持：再次提取 | 用真实检索表现安排下次出现；重新练习时隐藏参考 | 作答、自评、协助标记和到期时间可保存；自评不升级掌握度 |

费曼机制可以回溯到其本人演讲，但现代四步“费曼技巧”属于后来的操作整理。Simon/Chase 的组块证据来自棋类任务；跨领域的目标聚焦流程是 forge 的产品抽象。康奈尔的机制来自官方操作单页，页面形式可以采用图谱与练习面板。

详细机制出处见技能包内 [sources.md](../skill/forge/references/sources.md)。公开来源与授权边界见[第三方说明](../THIRD_PARTY.md)；机制出处不等于本次实现验收或学习效果证明。

知识层级、内容难度和个人掌握度分别显示。阅读、展开节点、生成导图、写完笔记均不自动构成掌握证据；导师复核要引用仍对应当前内容的实际作答。更新概念或题目后，旧依据仍保留在历史中，但不再显示为当前掌握。

## 把学习循环延续到下次

场景：今天停在一个尚未解释清楚的概念，下次希望接着真实缺口学，而不是重新开始。主题档案保存目标、原答、协助、修正与暂停位置；本地索引定位已登记主题，选定后读回仍有效的内容与证据，再按时间预算续学或复习。索引不复制掌握结论，也不把档案更新时间当成实际学习时间。

可在会话中请求：`/forge 查看已登记主题，让我选一个，读回上次位置与缺口后继续。` 没有索引时需提供已有目录，独立浏览器缓存需先导出并导入。完整操作见[场景与使用示例](../skill/forge/references/usage-examples.md)和[学习档案入口](../skill/forge/references/learning-library.md)。
