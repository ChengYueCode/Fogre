# Forge 技能结构与维护约定

主技能名、调用名与安装目录名均为 `forge`；独立能力使用唯一的 `forge-*` 名称。旧安装目录 `ember` 中的 `name: forge` 应迁移到同一宿主技能根目录的 `forge`，保留旧文件在技能根目录之外，避免宿主发现两个相同身份。仓库目录名不决定技能身份。

## 编排与能力

- `skill/forge/SKILL.md` 选择本次范围、组织学习轮次、保存与续接任务；进入能力时读取自己的参考，无需依赖兄弟技能安装。
- `skill/forge/references/` 是能力规则的唯一正文，包含提问、材料核对、产物、复核、复习、洞见，以及共享交接约定。
- 五个单项目录由 `scripts/build-entries.mjs` 生成：`forge-question`、`forge-organize`、`forge-review`、`forge-review-plan`、`forge-insights`。入口保留触发、范围、示例和先读文件；详细规则按当前分支读取。

安装主技能即可用自然语言选择单项能力。单项入口也可独立安装；参考链接的递归依赖随包复制，保留本地链接与章节锚点，不把必要规则降为无目标的文字提示。随附参考用于当前能力与交接，不授权展开其他能力。参考图有回环，所以各入口可能携带较多参考；随包携带不等于每次全部加载。

共享的目录登记由 `learning-registration.md` 维护，档案与产物失败恢复由 `archive-recovery.md` 维护，构建输出及幂等合同由 `artifact-rebuild.md` 维护；完整旅程与产物 schema 保留原章节入口并链接这些规则。产物 schema 不拉入现场教学流程，登记不拉入完整续学，单项交接不拉入完整旅程。当前整理入口携带 14 份参考，复核携带 6 份；生成与隔离链接测试检查必要能力入口及重建/恢复规则仍可读，并约束它们不再次带入完整旅程或总路由。减少依赖须保留本能力实际需要的规则及本地可读链接，不能只隐藏失效路径。

主入口只保留范围判定、条件路由、执行等待与保存交付；具体流程和字段由参考持有。复习安排先交付只读预览，显式要求保存时才应用到已有适用轮次；洞见只聚合已有记录，空档案不填入作者内容。缺目录、缺轮次或记录不可读时说明缺项，不擅自初始化学习或伪造表现。

## 分发与宿主发现

仓库 `skill/` 下的六个目录是并列的分发单元，每个 `SKILL.md` 声明唯一 `name`。主技能把全部能力作为参考规则编排；它没有嵌套五个独立入口，安装主技能不会自动注册另五个调用名。

根目录 `.claude-plugin/plugin.json` 以 `forge-skills` 为插件名，显式列出六个 `./skill/forge*` 目录。Skills 据此发现技能，并在交互选择菜单显示可展开的 `Forge Skills` 分组；插件名不会改变技能身份或安装目录名。清单随源码发布包及 npm 包分发，增加或移除入口时必须同步维护。

六个入口均携带自己的 `SKILL.md`、能力参考与 `agents/openai.yaml`，UI 提示和会话示例使用对应的 `/技能名`。单项入口及其 UI 配置由同一个生成器维护；定位随附资源时使用实际加载的技能目录，不依赖源码路径或兄弟安装件。真实 npm 包测试对六个入口分别隔离安装，比较全部分发文件、检查本地参考，并对五个带工具的入口运行 CLI 校验与页面/导图构建；纯会话的 `forge-question` 不携带 scripts/assets。

默认仓库安装命令让用户在菜单中选择；`--skill forge` 只选择主技能，`--skill '*'` 直接选择全部六个。目标 Agent 与项目级/用户级范围决定实际加载位置；复制安装时，同一 Agent 的六个入口在其技能根目录下并列，完整资源随各入口携带。推荐位置与实测边界见[安装目录与发现检查](installation.md#安装目录与发现检查)。

npm 包 `forge-learning-local` 虽含全部六个分发目录，`npm install` 只安装 CLI。自带 `install-skill` 一次显式复制一个技能；要放置六个入口需逐一调用，不能把 node_modules 中的分发目录视为已被宿主发现。

当前结构无需把子技能移入主技能。六个并列身份更适合独立发现；把它们嵌套在 forge 内，反而会依赖宿主递归扫描规则。临时副本与升级备份继续放在扫描根目录外，避免重复身份；安装记录、资源可读和宿主真实发现/调用分别验证。

`forge-question` 的独立模式只使用真实会话输入，不携带运行程序、不创建档案；解释、帮助、停止与缺依据的处理均在其先读规则内。需要持久保存或进入完整教学时说明范围变化，再使用可用的完整入口。其余入口携带 CLI 和页面资产，以支持本能力中的档案读写及复核后重建。

## 学习输出路径

`output-paths.md` 是学习路径合同，主技能与四个带工具的独立入口按同一规则执行。相对路径按命令工作目录解析；工具资源按技能位置定位，学习命令必须显式传 `--out`。CLI 在创建目录与锁之前检查写入目标，构建、服务、索引及共享写文件层使用同一技能目录保护；允许读取随包模型，拒绝在 Forge 技能目录内写学习数据。路径别名解析后指向技能内部也拒绝。安装器和开发生成器的合法写入用途单独保留。

## 维护与验证

修改 `skill/forge/references/` 或主入口；单项入口的名称、触发和先读映射在生成器内维护。生成目录不手改。运行：

```sh
node scripts/build-entries.mjs
node scripts/build-entries.mjs --check
node scripts/check-links.mjs
node --test tests/entries.test.mjs
npm run test:distribution
```

`--check` 在临时目录生成比较结果，发现过期时返回失败，保留现有文件供检查。验证须包含单独安装后的参考可读，以及 CLI 所需资产是否可用；链接存在不证明教学行为已通过真实使用验收。

保留既有缓存键、锁协议、`customData.ember` 与历史迁移标识，它们是持久数据兼容约定。主入口和单项入口保持已有自动发现策略；分层不要求改变调用权限。源码验证、个人技能安装、当前会话发现和公开发布分别记录。
