# 展示图生成提示词

工具：内置 image_gen；生成模式为以实际截图为参考的展示合成，主视觉另有一次局部修正，学习流程图另有一次按用户参考形象的人物替换。提示词只记录生成意图，最终图片的实际内容仍需视觉核对。每次重新生成会产生不同图片。

品牌依据：当前 Forge、Make sense. Keep going.、中文定位与主技能界面信息中的 #3F6B4F。实际截图与生成展示图分别登记；来源和文件 SHA-256 见 [manifest.json](manifest.json)。
