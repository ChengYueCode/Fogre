# 本地索引定位学习档案

2026-10-11，用户确认补充统一学习档案入口，减少再次交流时寻找主题目录的成本。

学习记录继续保存在各主题 `state.json`，本地索引仅保存主题身份、模型身份、目录指针和登记时间。列表实时读档案，避免缓存摘要与真实学习状态漂移；续接复用统一恢复读取，不新建轮次或合并画像。默认入口为当前工作区 `learning/learning-index.json`，一个索引对应一个学习者，其他工作区需明确指定位置。

登记显式进行，目录相对索引定位，可整体携带；主题损坏时隔离显示，索引损坏时拒绝写入。移除只移除指针。这个入口解决本地发现与导航，不引入账号、云同步、后台教学或跨主题掌握推断。
