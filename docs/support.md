# 环境与支持范围

| 环境或路径 | 状态 |
| --- | --- |
| Windows、Node.js 24.16.0、npm 12.0.2 | 已有本地工具及真实 npm 包安装验证；最新结果见验收说明 |
| Node.js 20 及以上 | 当前声明的最低要求；CI 配置覆盖 20 与 24，配置存在不等于远程执行通过 |
| Linux | 已配置 CI 验证；尚无本次运行结果 |
| macOS | 未完成本次平台验证 |
| Codex 技能目录 | 已有本地完整安装验证；本次没有升级用户个人安装 |
| GitHub 远程技能安装与真实宿主调用 | 需在真实仓库发布后分别验收 |
| 独立 HTML、自动存档服务 | 保存方式不同，见安装指南；缓存不是会话已读回的档案 |

完整产物与存档需要宿主支持技能发现、文件读写和命令执行；仅有文本对话能力不足以调用本地工具。其他 Agent 的兼容性按真实发现、调用、保存和重开结果记录。

反馈时提供安装来源、版本、保存方式和匿名复现。历史 `ember` 缓存键及档案标识是兼容约定，不按品牌名称机械替换。
