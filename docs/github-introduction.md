# Forge

**Make sense. Keep going.**

**帮你学新知识、整理资料、检查答案，并保存进度。**

你可以把 Forge 安装到支持技能的 AI 助手中。安装后，在聊天里输入 `/forge`，写上想学什么或提供材料，它就会结合讲解、例子和练习带你学习。结束时可以保存回答和进度，下次读取记录后继续。

这份说明面向第一次使用的人。安装工具、文件格式和维护命令的详细信息放在[安装指南](installation.md)与[开发资料](#项目资料与开发)中。

## 适合用来做什么

| 你想做什么 | Forge 会怎样帮你 |
| --- | --- |
| 学一个新主题 | 先了解目标和基础，用例子讲解，再让你试一试 |
| 整理文章或笔记 | 整理成学习网页、思维导图和练习，保留资料出处 |
| 检查自己的解释 | 提出问题，看看你的想法是否遗漏条件或理由 |
| 检查已经提交的答案 | 读取已保存的答案，逐题说明正确部分和具体问题 |
| 安排今天的复习 | 根据已有记录和时间，说明这次先复习什么 |
| 找回以前学过的主题 | 查找已经登记的学习文件夹，读取各主题的进度 |
| 接着上次学 | 读取以前的回答、反馈和暂停位置，继续未完成的内容 |
| 回看理解上的变化 | 把原来的解释、后来的修改和反馈放在一起 |

可以从头学习，也可以只请它整理资料或检查理解。你随时可以请求换个例子、调整学习目标或暂停。

## 安装技能

不熟悉安装步骤，可以先把这段话交给你正在使用的 AI 助手：

```text
请从 https://github.com/ChengYueCode/Fogre 为我安装 Forge。
请安装 forge 和五个 forge-* 技能，共六个，检查能否使用，告诉我怎么开始。
已经装过时先核对现有版本，缺少必要环境时说明需要我做什么。
```

你的助手需要支持技能安装、读取和保存文件、运行命令。生成学习网页和保存记录还需要 Node.js 20 及以上；可以让助手检查环境。只会聊天、不能使用这些工具的助手，无法完成所有功能。各软件的实际支持情况见[环境支持](support.md)。

熟悉终端的人可以运行：

```sh
npx skills@latest add ChengYueCode/Fogre
```

展开 **Forge Skills**，选择 **Select All**（全部选择），再选择使用哪个 AI 助手和安装范围。只想安装主技能时选择 `forge`；它已经能处理全部功能，但只有 `/forge` 这个调用名字。安装五个其他技能后，才能直接使用它们各自的名字。

默认安装在当前项目；增加 `--global` 可在其他项目中使用。更详细的命令与升级方法见[安装指南](installation.md)。安装后还要按助手软件的要求加载或刷新，并确认可以使用。

## 直接在 AI 助手里开始

在聊天中输入 `/forge`，后面写你想做什么。材料可以作为附件提供，也可以放在助手能够读取的文件夹中。例如：

```text
/forge 带我学习这份课程笔记，用例子讲解，再让我自己解释一遍。
我今天有 20 分钟，结束前请保存进度。
```

你可以补充自己的基础、偏好和今天可用的时间。没有必要每次填写完整表格，也不用自己准备程序或数据文件。缺少会影响这次学习的信息时，助手会说明。

## 使用实例

下列请求是用法示例，不是已经发生的学习记录。更多情况见[完整请求示例](../skill/forge/references/usage-examples.md)。

### 先整理材料，今天不提问

```text
/forge 把我提供的笔记整理成学习网页和可编辑思维导图，保留疑问和来源，今天先不提问。
```

它会先阅读材料，再给出网页、导图和练习，说明保存位置。整理完成不代表你已经学会这些内容。

### 检查自己的解释

```text
/forge 只通过提问检查我的解释：“两件事一起发生，就说明其中一件导致了另一件。”
每次只问一个问题，等我回答。
```

它会围绕一个关键问题追问。你想听讲解时，可以直接说“这个地方没理解，请解释一下”。

### 检查已经做过的题

```text
/forge 检查这个学习文件夹里我已经提交的答案，说明哪里答对、哪里有问题、怎样修改，并保存反馈。
```

需要提供包含答案的学习记录。原答案会保留，修改另存；材料不够或暂时无法判断的题目会说明。

### 只有 15 分钟，安排复习

```text
/forge 根据这个学习文件夹里的记录安排 15 分钟复习，优先处理我反复答错的地方，说明哪些留到下次。
```

它会先给出复习安排和理由。明确要求保存后才写入适用的学习记录；给出计划不代表已经完成复习。

### 今天先停，下次继续

```text
今天先停在这里，请保存进度和没解决的问题，告诉我下次从哪里继续。
```

下次回到原项目时可以说：

```text
/forge 找出我上次的学习记录，告诉我停在哪里，再接着学。
```

如果没有找到记录，它会先询问文件夹的位置。多个主题同时存在时，由你选择这次继续哪一个。

## 一次学习中你和 AI 分别做什么

| 什么时候 | 你做什么 | AI 助手做什么 |
| --- | --- | --- |
| 开始 | 提供主题、材料或想解决的问题 | 读取材料，和你明确这次先学什么 |
| 讲解和练习 | 自己解释、做题，指出不懂的地方 | 根据回答讲解、提问、给例子或示范 |
| 检查答案 | 提供真实回答，必要时修改 | 说明正确部分、具体问题和修改建议 |
| 结束 | 决定暂停或结束 | 保存记录，说明没解决的问题和下次起点 |
| 下次 | 提供记录位置或选择已有主题 | 先看旧记录，再继续学习 |

Forge 的讲解者就是你当前使用的 AI 助手。学习网页用于阅读、练习和保存，不会自己在网页里和你聊天。

## 学习页与学习档案

“学习页”是用浏览器打开的网页，可以看解释、做练习、记笔记。“学习档案”就是保存下来的学习记录，其中包括目标、答案、修改、反馈和暂停位置。

这些文件只在需要时生成。只在聊天里检查解释时，不必生成整套文件。

### 保存在哪里

记录放在你选择的学习文件夹里。让助手告诉你位置，并检查是否已经保存成功。下面是常见文件名；正常使用时，让助手处理即可。

| 文件 | 内容 |
| --- | --- |
| `index.html` | 可以打开阅读和练习的学习网页 |
| `model.json` | 这次学习的知识、问题、参考和材料出处 |
| `state.json` | 你的回答、修改、反馈和进度 |
| `map.excalidraw` | 可以编辑的思维导图 |
| `map.svg` | 按需生成的导图预览图片 |
| `quality.json` | 对材料整理质量的检查记录，不是你的学习成绩 |

### 下次如何找到学习记录

助手会把标准学习文件夹登记到一份目录清单中，方便以后查找。清单只记录文件夹位置；答案和进度仍放在各主题的文件夹里。

在原项目中，可以请求“看看我以前学过哪些主题，让我选一个继续”。换电脑或项目时，需要带上清单和对应的学习文件夹，并告诉助手新位置。文件不见了或无法读取时，助手会说明，不能把缺少记录当成你从未学过。

### 在页面作答后怎样继续

- **助手给你一个本地网页地址**：保存服务正在运行时，网页可以直接把答案存进学习文件夹。保存成功后，让助手检查这些答案。
- **直接双击 HTML 文件打开**：新增答案先留在当前浏览器中。点击“导出状态”，把文件交给助手核对、导入并检查。
- **检查答案或材料更新后**：让助手更新网页，再重新打开或刷新，查看新的反馈。

不确定是否保存时，直接问：“我刚才的答案保存在哪里？你现在能读到吗？”网页本身不会自动请 AI 批改答案。

思维导图可以用 Excalidraw 打开并编辑。编辑后把文件交回对应学习文件夹，请助手更新网页并保留修改；改图里的文字不会自动改变练习题和参考内容。

## 单项技能入口

这里的“入口”就是在聊天开头使用的名字。`/forge` 可以处理全部功能；下面五个名字各自只做一件事，需要安装并加载对应技能。

| 名字 | 用来做什么 |
| --- | --- |
| `/forge-organize` | 整理资料，生成学习网页、思维导图和练习 |
| `/forge-question` | 用提问检查你自己的解释，每次一个问题 |
| `/forge-review` | 检查学习记录里已经提交的答案 |
| `/forge-review-plan` | 根据已有记录和今天的时间安排复习 |
| `/forge-insights` | 回看以前的解释、修改和反复出错的地方 |

例如，只安装检查理解的技能，可以在终端中使用：

```sh
npx skills@latest add ChengYueCode/Fogre --skill forge-question
```

## 常见问题

**需要会编程吗？**

正常学习不需要。你提供材料、说出目标、自己回答，文件和工具由 AI 助手处理。安装和运行环境有问题时，先让助手说明缺少什么。

**必须生成网页吗？**

不必须。你可以只聊天，也可以明确要求整理网页或导图。保存了哪些记录，以实际结果为准。

**换一次聊天还能继续吗？**

可以依据已保存的记录继续。仍在原项目时让助手查找；换电脑或项目时，要提供迁移后的学习文件夹。它不会自动知道其他设备上有哪些记录。

**任何 AI 助手都能用吗？**

需要助手软件支持技能加载。完整功能还需要文件读写、命令执行和 Node.js；不同软件的实际支持情况见[环境支持](support.md)。

**能完全离线使用吗？**

学习文件可以放在电脑上，但 AI 模型、读取网络材料或在线编辑器可能需要联网。具体由你使用的助手软件和模型决定。

## 能力边界

- 生成了网页、阅读了笔记或做完了题，不会直接被记作“已经学会”。判断要根据你实际怎么解释、怎么回答。
- AI 的解释和反馈可能出错，发现疑问时可以让它核对原文并更正。
- 没有保存的内容，不能当成下次一定能找到的记录。
- 记录不会自动在不同电脑之间同步，也不会自动把所有主题排成一个总复习计划。
- 学习网页没有内置 AI 聊天，也不会在后台一直替你上课。
- 复习使用简单、可说明的规则，不承诺固定时间学会或永久记住。
- 公开的示例答案和工具演示不是真人学习效果的证明。
