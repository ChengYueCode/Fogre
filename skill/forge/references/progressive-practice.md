# 依据表现选择练习与分步帮助

在需要根据已保存作答组织后续练习、修补已核对缺口或设计逐步提示时读取。

现场回应后的推进/等待、完整演示、起步帮助与案例范围先按[主动教学](adaptive-teaching-and-cases.md)处理。`practice` / `submit` 的协助来源支持 hint、reference、tutor-feedback、starter（起步帮助）与 demonstration（完整示范）；都保留有协助属性。演示不创建学习者答案，随后真实尝试用同一练习身份继承来源。提问策略下的问题是否算帮助，按问题实际内容用同一协助来源判定，见[苏格拉底提问](socratic-questioning.md)的帮助判定。

作者问题的 `teaching` 字段与校验以[模型字段约束](artifacts.md#字段与校验约束)为准。判定标准仍使用问题 `criteria`；作答前的完成标准只表达可观察行为，具体细则在提交后或主动查看参考时显示。所选题目的必要前置进入本轮路线。内容须来自实际材料与核对，不能为了满足任务类型凭空生成未经核对的规则。未配置的旧题按原问题类型使用现有内容。

```bash
node <skill-dir>/scripts/forge.mjs practice-plan --out <dir> [--round-id <ID>]
node <skill-dir>/scripts/forge.mjs round --out <dir> --action update --round-id <ID>
node <skill-dir>/scripts/forge.mjs practice --out <dir> --prompt <ID> --session-id <稳定ID> --hint-level 1 --assistance hint
```

先只读计划并核对选择依据，再按学习者决定更新本轮。页面练习选择器和本轮更新使用同一选择规则：没有可核对成功表现时先解释与补漏；已核对的独立解释成功可进入变式或新情境，帮助后的成功与修正不冒充新的独立表现。纯自评、未评价、过时内容和点击行为均不作为升阶依据。不存在适当任务时先补题目与判定依据，当前内容缺口仍保持未通过。

在页面主动点击“查看提示（标记为有协助）”，每次只多显示一条，进度随同一次练习保存；关闭重开仍恢复已查看步骤。完整参考可以主动查看，也计为协助。提交原答不必自评，原文及有协助属性保持不可变；反馈后修正仍单独追加并声明帮助来源。自创问题可练习与复习，缺作者依据时如实保留讨论和自评边界。

同一次练习的 `hintLevel` 只增不减，不超过当前内容可用提示数；每次推进保留 `hint` 协助来源。旧档没有 `hintLevel` 时保持字段缺席，不补造查看帮助的历史。

调整路线不会删掉已经提交的原答，已移出的旧任务仍保留原归属。暂停、续接和重建后读取同一轮次，依据当前内容重新安排，不静默把旧作答升级为新内容证据。保存与独立模式交接步骤见[完整旅程](phase-delivery.md)和[集中复核](tutor-review.md)。
