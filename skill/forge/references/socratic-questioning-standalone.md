# 苏格拉底式提问：会话规则

围绕学习者提供的目标、主张或解释检查一个具体缺口。先说明本次范围；依据不足时检查概念与论证结构，事实结论保持待核对。一次提一个主要问题，停等真实回答；纯会话模式无需学习档案、运行程序或文件写入。

## 提问与等待

1. 盘点当前解释中仍不确定的前提、依据或推论，选择一个有用的缺口。问题针对学习者自己的推理，不是一次检索就能回答的事实复述，也不以「是否／对不对」代替解释。
2. 提一个主要问题，标注下表中的问题类型，再用一句话说明想检查哪个认知；等待真实回答，不模拟回答或替学习者补答。
3. 收到回答后内部核对依据、实际协助与缺信息，再选择继续追问同一缺口、转向新缺口或结束。默认通过问题检查，不评价对错或打分；用户明确请求解释、点评或核对时，按新请求处理并说明结论范围。

| 类型 | 针对的缺口 |
|---|---|
| 澄清 | 含义不明、概念混用 |
| 追问假设 | 隐含前提未说明 |
| 追问证据 | 理由、数据或依据缺位 |
| 追问视角 | 反例、边界或迁移 |
| 追问后果 | 前提变化后结论如何变化 |
| 追问问题本身 | 问题或目标是否问对 |

按当前缺口选择类型，不机械走完六种。问题从已提供的解释出发，未知条件先问清；例子中的假设明确标为假设，不能替学习者补造其未给出的实现细节。

## 回应、帮助与退出

- 「不知道／没理解」：提供够开始的一步提示或换一种简短解释，如实说明已提供帮助，再等待真实尝试。
- 「好的／ok」但仍未回答：保留当前问题等待，不算实质作答。
- 「直接解释／请点评」：按新的请求提供解释或有限判断；不因此创建学习档案。
- 「停止」或已有预算耗尽：即时结束。无硬预算时可建议只检查当前判断，不制造已同意的上限。
- 当前缺口已得到足够澄清：简短说明已看见什么、依据与尚未验证的点，结束单项任务；不把局部检查扩成完整教学。

中性澄清不自动算提示。透露关键机制、排除关键选项或指向答案的问题属于实际协助；协助后答对不称为独立回忆成功。只根据真实回应说明当前表现，不推进掌握度。

## 输出与恢复

提出问题后说明正在等待；结束时报告结论范围、依据、未解决缺口与实际帮助。纯会话没有持久保存，不能宣称归档或安排了持久复习。材料不可读时限制结论，说明缺什么和可行的下一步。

用户请求保存或进入完整教学时，说明目标已改变，再选择可用的完整入口；未安装对应入口时如实说明所需能力。已有教学任务调用本规则时，任务身份、帮助保存、进度计数与返回位置由调用方管理，本规则只交回当前缺口与实际回应。
