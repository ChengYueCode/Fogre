# 输出位置与保存合同

处理学习目录、外置档案、导图、导出或主题索引路径时读取。本规则与随包 CLI 的解析一致；技能安装位置只定位工具与模板，不决定学习数据位置。

## 确定学习位置

用户已指定目录时沿用它；续学时沿用读回的原目录。未指定的新主题可使用当前会话工作区的 `learning/<主题ID>/`，向用户说明实际绝对路径；这由 Agent 选择，脚本没有自动主题目录默认值。调用前确认执行命令的工作目录，并尽量把选定路径传为绝对路径，避免切换终端目录后保存到另一处。不要为运行工具而 `cd` 进入技能目录。

## 脚本实际解析方式

| 参数或操作 | 实际位置 |
| --- | --- |
| `--out <目录>` | 必须显式提供；相对路径从命令执行时的工作目录解析，绝对路径定位指定目录 |
| 默认模型、档案、页面、导图、质检记录 | `<out>/model.json`、`state.json`、`index.html`、`map.excalidraw`、可选 `map.svg` 与 `quality.json` |
| `--model` 或模型位置参数 | 输入文件；相对路径也按命令工作目录解析，不按技能目录或 `<out>` 解析 |
| 支持的 `--state` | 外置档案位置，同样按命令工作目录解析；只读命令读取，写命令写回该档案 |
| `import --state` | 待导入的输入文件；合并结果始终写入 `<out>/state.json`，不会改写导入文件 |
| `build --scene` | 指定导图既被读取也被写回；不自动另写 `<out>/map.excalidraw` |
| `export --to` | 必须指定导出文件；相对路径按命令工作目录解析，省略时报告缺少参数，不写文件 |
| `quality-template --to` | 指定新草稿文件；相对路径按命令工作目录解析，省略时仅打印骨架 JSON，不创建草稿文件 |
| `--catalog` | 指定索引文件；省略时使用命令工作目录的 `learning/learning-index.json`，不自动跟随外部 `<out>` |
| 索引中的主题目录指针 | 相对于索引文件所在目录解析；换工作区仍可用明确的索引路径找到同一主题 |
| `--quality`、`--backup`、`--feedback` 等输入文件 | 按命令工作目录解析；使用文件内容不意味着写回这些输入 |

学习脚本的文件写入入口会拒绝 Forge 技能目录内的输出，包括 `--out`、外置 `--state`、写回 `--scene`、`--to` 和可写索引；目录链接指回技能内部同样拒绝。只读输入仍可读取随包模型或需要迁移的旧记录。档案锁是工具协调元数据，不是学习产物；随包输入所在目录可能短暂出现协调锁，释放后移除。

## 浏览器与交付

`serve --out` 页面把合法增量写回对应档案（有 `--state` 时写回外置档案）。直接打开 HTML 只保存浏览器缓存。页面“导出状态”生成下载文件，实际下载目录由浏览器决定，不自动写回学习目录；提供并核验导出文件后，再用 `import` 归入选定目录。

完成时读回工具返回的实际路径，分别报告“文件已写入”“只在会话中输出”“浏览器缓存”或“浏览器下载”。绝对 `--out` 指向另一目录、但没有指定 `--catalog` 时，索引仍位于调用工作区；不能把目录建议、命令工作目录和实际保存位置混为一处。

技能安装器的 `--target`、开发生成器和发布打包器有各自用途：安装器显式写技能安装目录，生成器维护独立入口，打包器写发布候选；它们的输出不是学习档案。
