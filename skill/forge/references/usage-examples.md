# Forge 场景与使用示例

在已安装并加载 Forge 的 Agent 会话中使用以下请求。`$forge` 是支持该写法的宿主中的技能调用前缀，不是终端命令；其他宿主使用其实际调用方式。材料需作为附件提供，或位于 Agent 有权读取的位置。示例目录相对当前会话工作目录解析；更换工作区时提供索引或档案的可读位置。

这里的场景与回答片段用于说明用法，不是真人学习成果。你只需提供目标、材料和真实回答，Agent 按规则调用工具；完整产物与存档需要文件读写、命令权限和 Node.js ≥20。保存结果以实际读回为准。

## 1. 学新主题：看过代码，但说不清为什么正确

**场景**：你能读简单代码，学过二分查找，却容易混淆左右边界，希望这次能解释正确性，而不只是背模板。

```text
$forge 带我学习二分查找，目标是独立解释循环不变式，并判断边界是否正确。
我能读简单代码，但容易混淆左右边界。这次有 20 分钟。
请把产物和记录放在 learning/binary-search。
```

**预期处理**：核对相关基础与材料，提出一个诊断问题并等你回答，再按真实缺口校准有限路线。需要时生成学习页和可编辑导图；保存目标、原答、协助、修正与暂停位置，并登记主题目录。预算不足的部分明确暂缓，不把路线已提交说成已掌握。

## 2. 只整理材料：已有笔记，希望得到可探索的学习产物

**场景**：你有课程笔记或文章，想先看清概念关系，暂时不接受现场提问。

```text
$forge 只整理我提供的二分查找笔记，生成学习页和可编辑思维导图。
保留我的疑问，标明材料依据与尚未核对的部分。
请放在 learning/binary-search，不要现场提问或评估掌握度。
```

**预期处理**：核对可读材料并交付产物，不强制画像或诊断。学习页保留可复用的练习与参考，初始掌握度保持未知；已有目录先读回，重建保留有效记录，不重新初始化。同一请求可用独立入口 `$forge-organize`。

## 3. 检查解释：觉得懂了，想让问题暴露漏洞

**场景**：你能给出解释，但不确定它是否遗漏条件，希望先自己推理。

```text
$forge 只用提问检查我的解释：
“二分查找每次把范围缩小一半，所以任何有序数据都能直接套用同一种边界写法。”
先检查最关键的一个缺口。
```

**预期处理**：围绕一个缺口提一个主要问题，然后等待你的真实回答，不提前代答或评分。你可以请求改为讲解或停止。没有档案时在会话中讨论，不宣称已持久保存。同一请求可用 `$forge-question`。

## 4. 请求帮助：卡住了，需要换讲法或完整示范

**场景**：正在学习一项边界判断，你回答“不知道”，希望得到足够起步的帮助。

```text
这个地方没理解，请换一种讲法，给我一个完整示范，再让我自己试一个变式。
```

**预期处理**：沿用当前目标与任务，针对缺口提供解释、起步帮助或示范，保存真实协助来源，再等待你的尝试。示范后的作答按实际帮助情况记录，不算成无协助的独立回忆证据。学习用途的假设案例与真实业务决定分别说明。

## 5. 复核作答：已经提交，希望知道具体哪里有问题

**场景**：你已在会话或自动存档学习页完成一批练习，想集中获得反馈。

```text
$forge 检查 learning/binary-search 里本轮已经提交的作答。
说明正确部分、具体误解、核对依据和修补建议，保存反馈，并更新学习页供我查看。
```

**预期处理**：固定本轮复核范围，核对原答、题目、参考与判定标准，逐项保存并读回反馈。原答保留，修正另记；缺依据、内容变化或无法判断的项明确待处理。无轮次历史需先选择具体作答范围。同一请求可用 `$forge-review`。

## 6. 安排复习：时间有限，先补最影响当前目标的缺口

**场景**：今天只有 15 分钟，希望继续二分查找，不想重复刷所有题。

```text
$forge 根据 learning/binary-search 的记录安排 15 分钟复习。
优先处理左右边界相关的缺口，说明选中理由和暂缓项。
```

**预期处理**：根据这个主题的必要前置、主动重点、重复错误与真实到期项安排，说明预算内的选择与暂缓理由。没有到期记录就如实说明；未选中不等于完成或遗忘。这不是自动跨主题复习总计划。同一请求可用 `$forge-review-plan`。

## 7. 暂停：时间到了，希望保留下次的起点

**场景**：当前任务还没答完，你需要结束这次交流。

```text
今天先停在这里，请保存当前进度和未完成任务，说明下次从哪里继续。
```

**预期处理**：停止展开新任务，说明实际完成范围、未解决缺口、保存方式和档案位置，保留原轮次与暂停位置。未作答任务仍是未作答，不把“先停下”改写成路线完成。

## 8. 新会话续学：忘记目录名称，想找回已有主题

**场景**：仍在原工作区，之前学习的主题已经登记，但你不记得目录名称。

```text
$forge 我想继续之前的学习。先查看当前工作区已登记的主题，
告诉我各自停在哪里、还有哪些缺口和待复习内容，让我选一个继续。
```

**预期处理**：读取本地索引并实时读回主题档案。选定后恢复目标、位置、原答、协助、画像和材料变化，再续接适用的原轮次。索引缺失时询问已有档案位置，不把空索引解释为从未学习；缺文件的主题明确报错，不建立空档案。

如果主题或目录已明确，可以直接说：

```text
$forge 继续 learning/binary-search 的学习。
先读回上次目标、暂停位置、原答、反馈和缺口，再接着学。
```

## 9. 换工作区：带着档案继续，而不是依靠旧聊天

**场景**：你将学习目录和索引整体复制到了新工作区的 `my-learning/`，需要找回其中的主题。

```text
$forge 我的学习索引是 my-learning/learning-index.json，相关主题目录也已一起迁移。
请查看这个索引，找到 binary-search 主题，核对材料或目标是否变化后继续。
```

**预期处理**：使用指定索引及相对它定位的档案，读回旧记录与当前差异。文件不可读或指针失效时先核对位置；索引不自带题目与答案，需要对应主题目录。不会自动搜索所有设备或同步账号。

## 10. 独立页面交接：浏览器里做过题，会话还没收到记录

**场景**：你直接双击 HTML 做了练习，新增答案保存在浏览器缓存，现已从页面导出档案。

```text
$forge 我从学习页导出了 backup/binary-search-state.json。
请核对它是否属于 learning/binary-search，导入后复核真实作答，并更新学习页。
遇到冲突请保留并说明。
```

**预期处理**：核对模型、内容版本与来源，合并合法记录，处理冲突，复核并重建可信新版页面。导出不等于导入，导入不等于复核；没有收到可读导出文件时不能声称读取了浏览器答案。

## 11. 回看理解变化：从原来的误区里形成复习线索

**场景**：已学过几轮，希望看到自己对左右边界的解释如何变化，而不是再生成一篇通用总结。

```text
$forge 汇总 learning/binary-search 中我的误区和理解变化。
按概念展示原答、修正、反馈和自创问题；没有记录的部分不要补写。
```

**预期处理**：只聚合已有档案，区分当前内容、历史答案和缺失记录，不新建事实或增加掌握证据。同一请求可用 `$forge-insights`。

## 12. 纠正讲解：发现 AI 的说明与材料原文冲突

**场景**：你核对原文后发现讲解或参考答案可能有错，需要连同受影响的练习与记录一起检查。

```text
你对终止条件的讲解与我提供的原文不一致。
请回读原文，核对受影响的解释、练习、参考和记录，保存纠错依据并保留我的原答。
```

**预期处理**：先回读相关原文，再说明准确解释和依据，核对六类影响并保存纠错历史。受误导原答保留，后续尝试另行关联；纠错本身不证明你已掌握。

## 选择单项入口

主技能 `$forge` 可以处理以上完整学习与单项请求。只想独立调用一项能力时，安装并确认宿主发现对应入口后使用：

| 入口 | 场景 | 可复制请求 |
| --- | --- | --- |
| `$forge-organize` | 只交付已有材料的学习产物 | `$forge-organize 只整理我提供的笔记，生成学习页和可编辑导图，保留疑问与来源。` |
| `$forge-question` | 用一个问题检查解释 | `$forge-question 检查我的解释：“有序数据都能套同一种二分边界写法。”先问一个问题并等我回答。` |
| `$forge-review` | 检查已保存的真实原答 | `$forge-review 检查 learning/binary-search 本轮作答，保存逐项反馈。` |
| `$forge-review-plan` | 在时间预算内安排主题复习 | `$forge-review-plan 根据 learning/binary-search 的记录安排 15 分钟复习，说明选择和暂缓理由。` |
| `$forge-insights` | 聚合已有理解变化 | `$forge-insights 汇总 learning/binary-search 的原答、修正和误区，不补造记录。` |

仅安装主技能就能用自然语言选择这些能力，不需要安装全部入口。档案查找、续学和完整交接使用 `$forge`。
