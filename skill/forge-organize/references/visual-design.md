# Forge 产物视觉设计

生成或重建 HTML、导图、SVG 或速查产物时使用本参考。Forge 从来源技能提炼学习机制，交付物的配色、排版、页面构图与装饰由 Forge 按本次内容重新设计；来源课件和截图用于理解用途，不作为视觉模板。机制出处仍按 sources.md 标注。

## 从内容选择表现

先核对目标、知识关系、学习者实际缺口和主要阅读动作，再选择视觉主题。已有主题续学时读回 `model.json` 中的 `presentation`，没有内容或用户偏好变化时延续原选择。只有交付物生成任务才需要此步骤，现场提问不强制生成页面。

| 主题 | 适合的任务 | Forge 的表现 |
|---|---|---|
| `atlas` | 探索层级、前置与跨分支关系 | 冷白与钴蓝，关系图占较大宽度，层级节点清晰 |
| `lab` | 改变条件观察结果 | 青白与深青，实验面板占较大宽度，数字便于比较 |
| `sequence` | 算法、协议或机制逐步推演 | 淡紫与紫色，网格画布、小圆角与过程感 |
| `contrast` | 区分易混对象与观点 | 浅玫瑰与莓红，均衡双栏与侧边标题标记 |
| `editorial` | 长文精读、解释与知识整理 | 灰白与橄榄色，衬线标题、宽阅读栏与轻分隔 |

这些是本地构建器支持的表现，不是所有学习主题必须逐一轮换的目录。相同结构可以使用相同主题；差异应来自阅读与学习需要，不为凑差异随机换色。复合主题按本次主要任务选择；用户明确偏好优先。具体知识内容、关系与互动组件仍由材料决定。

在模型中显式保存选择和简短依据：

```json
"presentation": {
  "theme": "sequence",
  "rationale": "学习目标是逐步解释协议状态变化，主要阅读动作是前进、回退和对照每步原因。"
}
```

未配置时，构建器按已有组件依次选参数实验 → 分步推演 → 对照组件/对比关系 → 关系探索。精读主题由作者显式选择；构建器不根据标题猜学科。主题只改变表现，独立于模型知识指纹、问题身份、作答事实和掌握度；选择颜色不产生学习证据。

## 跨产物与验收

- HTML、生成导图节点及 SVG 使用同一主题的背景、文字和层级色。导图重建仍通过三方合并保留学习者的手改颜色、布局及删除；手改背景保留，不能保证此时与新主题完全相同。
- 操作强调色与学习状态色分开。前置、因果、对比、应用的关系颜色和线型稳定；未知、待复核、需修补等状态有文字，颜色变化不改变含义。
- 从实际构建页验收：总览与正文的主次、390px 与桌面布局、键盘焦点、问题作答前隐藏参考、保存后重开、来源与缺口可见。新增主题需检验正文及控件对比度；视觉好看不能替代行为验收。
- 当交付静态速查或其他格式时，沿用当前主题的阅读层级与强调方式，并保留来源和不确定性。相同主题的产物应有视觉关联，不把互动页面截图冒充可编辑导图或可用学习档案。
