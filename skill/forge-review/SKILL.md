# forge-review · 集中复核作答

本入口只做一件事：对已保存的真实作答做导师侧集中复核。它不新建教学、不出新题，也不把复核结论当成新的作答。

## 场景示例

**场景**：learning/binary-search 中已有本轮作答，你想集中核对并留下反馈。

```text
/forge-review 检查 learning/binary-search 本轮已提交作答，说明正确部分、误解和依据，保存逐项反馈。
```

**预期处理**：固定复核范围、核对真实原答并读回反馈；原答保留，缺依据或内容失效的项保持待处理。

目录相对当前会话工作目录解析，材料需已提供且可读；保存情况以实际工具读回为准。

## 入口步骤

1. 按下方能力规则的顺序读取先读文件，在第一次回复里说明本次范围。后续只沿当前分支读取参考。
2. 命令使用本目录自带的 CLI：`node <本目录>/scripts/forge.mjs <命令>`，先用 `help` 查看当前命令；学习数据写在学习者指定的目录，不写入技能目录。
3. 按能力规则的等待点停等真实用户输入；完成时交代结果与未验证缺口，未持久化的内容如实说明。
4. 当前能力所引用的规则随附在本目录的 references/，单项任务无需另装主技能。参考中其他能力的说明只用于交接；用户改变目标时说明新的范围，再选择可用入口。
