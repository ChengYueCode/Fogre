# Forge · 检查答案

把已有学习记录的位置告诉它，让它逐题检查你已经提交的答案，说明答对的部分、具体问题和修改建议，并保存反馈。原答案会保留，你后来的修改另存；这项功能不会替你答题或新增练习。

安装并加载后，在会话中用 `/forge-review + 请求` 调用；安装参数与目录名使用 `forge-review`。以本次加载的 SKILL.md 所在目录定位随附文件，不依赖源码仓库、主技能或兄弟技能目录。

## 场景示例

**场景**：你已经完成并保存了一批练习，希望知道具体哪里答错了。

```text
/forge-review 检查 learning/my-topic 里我这次已经提交的答案，说明哪里答对、哪里有问题、怎样修改，并保存反馈。
```

**预期处理**：先确认要检查哪些答案，再逐题给出反馈。原答案保留；材料不够或暂时无法判断的题目会明确说明。

目录相对当前会话工作目录解析，材料需已提供且可读；保存情况以实际工具读回为准。

## 入口步骤

1. 按下方能力规则的顺序读取先读文件，在第一次回复里说明本次范围。后续只沿当前分支读取参考。
2. 命令使用本目录自带的 CLI：`node <本目录>/scripts/forge.mjs <命令>`，先用 `help` 查看当前命令；按[输出位置与保存合同](references/output-paths.md)确认执行工作目录与明确的学习路径，数据不写入技能目录。
3. 按能力规则的等待点停等真实用户输入；完成时交代结果与未验证缺口，未持久化的内容如实说明。
4. 当前能力所引用的规则随附在本目录的 references/，单项任务无需另装主技能。参考中其他能力的说明只用于交接；用户改变目标时说明新的范围，再选择已安装并加载的入口，缺少入口时如实说明。
