# Forge · 回看变化

读取已有学习记录，把你以前怎么解释、后来怎样修改、收到什么反馈放在一起，方便回看变化和反复出错的地方。只整理已经保存的内容；缺少旧记录时会说明，不能据此判断你已经学会。

安装并加载后，在会话中用 `/forge-insights + 请求` 调用；安装参数与目录名使用 `forge-insights`。以本次加载的 SKILL.md 所在目录定位随附文件，不依赖源码仓库、主技能或兄弟技能目录。

## 场景示例

**场景**：学了一段时间后，你想知道自己的解释发生了哪些变化。

```text
/forge-insights 回看 learning/my-topic 的记录，整理我以前的解释、后来的修改和反复出错的地方。没有记录的部分请说明。
```

**预期处理**：按知识点展示已有答案、修改和反馈。只有一次记录时会说明无法比较，不会补写你没说过的内容。

目录相对当前会话工作目录解析，材料需已提供且可读；保存情况以实际工具读回为准。
