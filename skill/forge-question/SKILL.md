# Forge · 检查理解

你先说出自己的解释，它通过追问帮你发现没想清楚的地方。一次只问一个问题，等你自己回答；这一项只在聊天里提问，不直接讲解、给答案、打分或保存文件。

安装并加载后，在会话中用 `/forge-question + 请求` 调用；安装参数与目录名使用 `forge-question`。以本次加载的 SKILL.md 所在目录定位随附文件，不依赖源码仓库、主技能或兄弟技能目录。

## 场景示例

**场景**：读完一篇文章后，你想检查自己的解释是否站得住脚。

```text
/forge-question 检查我的解释：“两件事一起发生，就说明其中一件导致了另一件。”每次只问一个问题，等我回答。
```

**预期处理**：围绕你的解释问一个问题，然后等待回答。不会直接替你给出答案，也不会把这次聊天说成已保存的学习记录。

目录相对当前会话工作目录解析，材料需已提供且可读；保存情况以实际工具读回为准。
