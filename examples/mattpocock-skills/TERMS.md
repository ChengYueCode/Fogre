# 学习术语速查

来源：[mattpocock/skills 固定提交](https://github.com/mattpocock/skills/tree/49dd158d1076134a641b33efb035946536778336)，2026-10-13 核对。中文说明、学习顺序与教学场景由 Forge 编写；未填入真人作答和掌握结论。

| 术语 | 在材料中的含义 |
| --- | --- |
| 用户入口 | 需要用户明确发起，其他技能和路由器不能自动替人发起。 |
| 模型入口 | 模型可按场景使用，用户也能显式调用。 |
| 路由器 | 阅读入口后建议选什么，不是自动流水线执行器。 |
| 纵向切片 | 窄而完整、能单独验证的跨层行为；宽机械迁移是例外。 |
| 阻塞边 / 就绪前沿 | 任务依赖以及前置已完成、可领取的工作。 |
| 决定任务 | wayfinder 解决的决定，不等同于交付实现的任务。 |
| Module / Interface | 模块与调用者须掌握的全部接口知识，不只类型签名。 |
| Depth | 少量接口知识带来的行为能力，不是代码行数比。 |
| Seam / Adapter | 可以替换行为的位置，以及在该位置满足接口的具体适配者。 |
| Leverage / Locality | 对调用者的能力收益，与对维护者的变更集中程度。 |
| Standards / Spec | 编码规范与需求符合度两条独立审查轴。 |
| 上下文指针 | 说明材料是什么，以及什么条件下应读它的引用。 |
| 流利 / 保持 | 当下可提取与长期存储表现；阅读和自评不自动证明保持。 |

概念依据来自 codebase-design、writing-for-agents、teach 和目录说明；详见来源清单。
